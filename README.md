# 🏥 We Care Hospital

A modern, responsive, and professional healthcare web application built with **React**, **React Router**, **Tailwind CSS**, and **Lucide React**. The platform is designed to provide patients with easy access to hospital information, medical departments, specialist doctors, healthcare services, and online appointment booking.

---

* Modern hero section with call-to-action buttons
* Hospital statistics and achievements
* About hospital section
* Why Choose Us cards

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/we-care-hospital.git
```

### 2. Navigate to Project Folder

```bash
cd we-care-hospital
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
